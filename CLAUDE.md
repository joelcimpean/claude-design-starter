# UI / Design System Instructions

Use the existing libraries in this project whenever building interfaces.

## Component libraries

- shadcn/ui
  - Use as the default foundation for buttons, dialogs, inputs, cards, tabs, sheets, menus and other standard UI.
  - Prefer existing components from `components/ui`.

- KokonutUI
  - Use for more creative, premium and visually interesting interface components.
  - Prefer existing components from `components/kokonutui`.

- Bklit UI
  - Use especially for charts, dashboards, analytics and data visualization.
  - Prefer existing components from `components/charts`.

## Animation libraries

- Motion
  - Default animation library.
  - Use for microinteractions, page transitions, hover effects, entrances and component animations.

- GSAP
  - Use for advanced animation timelines, scroll-based animations, parallax and complex sequences.

- Anime.js
  - Use for experimental animations, SVG animations, text effects and custom motion effects.

## General rules

- Prefer existing library components instead of recreating components from scratch.
- Use Tailwind CSS for styling.
- Build responsive interfaces.
- Keep accessibility in mind.
- Use tasteful animation rather than excessive animation.
- Aim for polished, modern, premium UI.
